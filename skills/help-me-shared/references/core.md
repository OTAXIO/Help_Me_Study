# 共享决策与边界

用户明确要求优先于默认惯例。复用已确认的课程、范围、结构和选择，跟进修改不重启无关流程。只分析、只本地稿、只同步已有内容分别遵守边界。

## 什么时候问

先查来源、上下文和已有偏好，能查证就自行验证。仍不明且实质影响正确性、范围、方法、结论、交付、页面目标或重要费用/时间时询问。实质来源冲突、关键数据缺失、跨课程/学期歧义不可猜。给少量选项、影响和推荐，合并同阶段问题；等答复做独立工作，沉默不算同意。

常规实现、措辞、排版、低影响可逆选择、有合理默认时自行决定，必要时说假设。用户已决定的不重复问。笔记大纲确认是明确步骤，不能用“减少询问”跳过，也不能扩张为逐小节批准。

## 真正完成与正式表达

区分实际阅读与摘要、实测与文献值/理论预期、已编译与已导出/视觉核验。不虚构数值、实验、日志、截图、个人经历或独立完成声明。正式作业自然表达，不放助手自述、聊天、prompt、Codex 标记、内部 QA 或无关日志；教师要求的工具声明保留。过程证据在工作目录，不自动进 submit。

## 范围和外部操作

- 获取材料不等于允许提交课程作业；生成笔记不等于允许写 Notion。已有明确范围内授权无需再问。
- 完成作业、老师要求 ZIP、Overleaf 要求均不自动授权压缩。submit 先散装；用户明确要求打包才压缩，另按其要求核验。此规则也管 Overleaf 源码包。
- 原始材料保留原位；只在本次 work 或经确认的 work_codex 下新增任务产物。共享跨会话状态例外，放用户目录。
- 凭据本地加载，不输出、提交或 shell-source；公开仓库不放真实课件/作业/字幕、Notion 内容/映射或身份信息。
- HPC 仅相关时读学校/用户规则，登录节点不跑重负载；缺身份不猜，重训练/付费/超范围先判断授权。

## 工具路由

已有专用工具优先。当前安装位置须实际发现，不写死个人用户名。只读对应技能的入口及需要的参考：

| 工作 | 外部能力 |
|---|---|
| 课程/字幕 | `sjtu-canvas-skill`，见 [Canvas 路线](canvas.md) |
| 文献理解、来源、获取 | [文献路线](literature.md) |
| 报告论证/润色、科学配图 | [报告路线](report.md) |
| 文档渲染 | 已有 PDF/文档/演示文稿工具；文件存在不等于视觉通过 |

依赖不在时用现有等价能力，明确能力缺口；确实需要且无法替代再向用户说明。避免不必要安装、复制整套外部技能或默认委派代理。
