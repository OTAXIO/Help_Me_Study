# Notion 页面定位、写入和状态

## 定位

有目标链接先用当前连接读取真实页面。课程还可查[状态 CLI](runtime.md)的课程/学期映射，核对名称、学期和层级；CLI 不联网，`verified_at` 只记录代理曾声明核验，不能证明现在可访问。映射明确不重复要链接，多学期/同名/失效先查询，不可靠才问。独立调研直接使用目标页，不伪造课程或学期来适配映射工具。

写入授权和课堂/调研的确认边界按[同步入口](../../help-me-notion-sync/SKILL.md)判断。状态不写宿主记忆、不进公开仓库，不因技能更新被覆盖。

## 写前

读取父页、相关子页、附件、作业入口、导航和用户指定保留内容。大改留工作目录下的 before 快照和页面 ID 清单；课程正文与页面结构分开处理。读取当前工具格式规范，不硬编码历史参数。

明确接口接收增强 Markdown 还是原生块/富文本。前者使用其支持语法并确认实际转换；后者将标题/列表/样式/公式/代码/表等映射为对应节点，不能写入带标记的普通文本代替样式。原生 Notion API 可核对 rich_text annotations 等结构，但不能假设当前连接器暴露原生字段。格式规范见[共享排版](formatting.md)，检查工具/边界见[格式检查](format-validation.md)。

已有格式问题先定位源、序列化、转换、写入或显示哪层，保留修前片段，精确修复并同步本地稿，不因格式改内容或删未知资源。重复转义不靠全局删反斜杠修复。

## 分批写与不明确结果

优先更新原页。课堂保持课程→章→必要拓展；独立调研按主题和目标页现有结构组织。保留子页、附件和不可识别资源块，不能用只含正文的父页替换抹掉资源。日志记录每批目标/动作/结果。超时先回读检查部分成功，再决定补写，禁止盲重试创建重复页。

## 回读

回读父页与每一受影响页，查标题/父子/导航/正文/公式/图/附件/重复/遗漏/未知块。视觉另查。未能回读不直接宣布成功；不可用交本地文件并说未同步部分。

同时查标题、列表、行内样式、代码、表格和引用是否以真实结构存在。若原生块快照可用，逐片核样式与内容；只有 Markdown 导出时不能假装已核原生样式。回读中合法标记不是可见泄漏，回读无标记也不证明样式正确。页面及全部分页/子块未取全要标覆盖不足，不宣称全页通过。

成功核对后把课程/学期、Canvas ID、父页及章/拓展的标题/URL/ID/父子、必要资料位置写本地映射。读取/更正/更新工具见 runtime；不要将随意猜的 ID 标 verified。父页改变需要实际用户意图，CLI 的 `--replace-parent` 不替代授权。
