# 笔记生成

## 大纲先行

先读课件与旧笔记，按需获取匹配字幕和只读 Notion 结构。用[模板](../templates/outline.md)给用户具体章节细纲、知识依赖与解释顺序、课程→章→拓展页面树、配图计划、材料覆盖/缺口、保留/调整/新增。等待明确确认；未确认只做资料准备，禁止完整正文及正式页面创建/改写。

已确认结构继续使用。明显更改范围或结构要重新展示，局部勘误不需整纲重批。跨会话可用[状态工具](runtime.md)保存大纲 SHA-256 和真实确认；内容指纹变化即旧确认不再证明新纲获批，但普通错字修正可在对话中记录仍属原授权范围，不伪造 CLI 审批。

## 教学主线

默认足够详细的中文复习笔记：为什么需要 → 直觉 → 定义/原理 → 推导 → 小例子 → 条件/局限 → 易错 → 知识联系。按主题灵活，不机械套标题、不堆术语或抄字幕。解释维度、条件、连续到离散、算法动机/步骤/复杂度、参数效果与相近概念对比；关键公式例子实际核算。

课件为骨架，课堂补直觉/例子/强调。分别标“课堂已讲”“课件拓展”“预习”，未知写“课堂覆盖待核实”；噪声字幕不作确定证据，外部来源不冒充教师。小结、对照、关系图、自测（答案便于先思考后看）与复习顺序服务记忆，不牺牲准确性。

## 层级与配图

课程入口导航 → 一章一子页 → 必要拓展子页。主线在章；长推导/背景/进阶例子可章下另页并链接，避免过深碎片化，不藏关键课程内容。

PPT 原图/表/局部截图与自绘流程/结构/坐标/关系图按解释需要选，不装饰性堆图。图近正文，注来源/页码或教学示意，说明读法/结论，留源文件。读[排版](formatting.md)。

小批次（如 1—2 章）生成核验，内部通过可继续，除非用户要求逐批审核。整体重排与局部修改分别遵范围。仅本地稿不写 Notion；同步另按[Notion](notion.md)写前读、资源保留与逐页回读。
