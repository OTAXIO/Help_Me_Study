# SJTU Canvas 与课堂证据

发现当前已安装 `sjtu-canvas-skill`，先读其 SKILL.md。按本次问题读取 review-workflow、incremental-review-updates 或 Windows 排查等需要的 reference，不默认全读。检查 CLI 文件和现有运行环境是否可用，不仅因 SKILL.md 存在就声称 CLI 可用。

1. 检查凭据是否已配置，仅确认存在不输出值；避免 `TOKEN` 缺失时交互挂起。API 用 TOKEN，视频/字幕还可能需 OC_COOKIE。
2. 从技能实际目录按当前文档运行 JSON CLI。中文课名先 `list-courses` 解析课程和学期，多结果查上下文再必要询问，不能猜 ID。
3. `list-assignments`、`list-files` 获取要求和材料 URL；URL 失效先重新获取。不猜下载链接。
4. `list-videos` 匹配日期/讲次/材料，再 `download-subtitle` 或 `study-note`。传入本次 work_<agent名> 下的输出位置，复用已核对缓存。
5. 映射课件页码、视频日期、时间戳、对应主题、老师强调与作业说明。不把整段转录粘作笔记，不把学生汇报误归老师要求。
6. 字幕无/噪声大时保留覆盖缺口；含混语音不能变成确定评分或作业要求。课件存在不能证明课堂已讲。

若解析失败，按当前技能提供的 Canvas tabs → external tool/sessionless launch → 视频资源客户端等实际入口回退，不硬编码历史课程/tool ID，也不把失败当不存在。缺 Cookie/权限时说明所缺，用户已有授权不重复索取。

## 补下载课堂资料

1. 核对 Canvas 的课程与学期，定位对应的本地课程名目录。已有课程目录直接复用；没有时在已确定的课程父目录下创建同名目录。用 `uv run main --json list-files <course_id>` 获取文件 ID、文件名、大小和下载 URL。课程级补下载检查该课可访问的文件，用户限定讲次或文件时遵守范围。
2. 在课程名目录直属层级创建或复用 `资料/课件`、`资料/作业`、`资料/其他文件`。先依据 Canvas 文件夹、作业附件或标题用途分类：题目、作业说明及其附件归 `作业`；授课幻灯片、讲义归 `课件`；其余及用途不明的归 `其他文件`。PDF 等扩展名不能单独决定类别。
3. 下载前查课程目录里的现有资料，包括已放在其他本地位置的课件。用可获得的 Canvas 文件 ID，或文件名与大小等元数据，确认是同一完整文件后直接复用原路径。名称相同但无法确认是同一文件时，下载后比对内容；相同就复用，内容不同就以 Canvas 文件 ID 区分文件名，保留两份。已有文件保留原位。
4. 对缺项调用 `uv run main --json download-file "<file_url>" --path "<该文件的临时目录绝对路径>"`。检查返回的 `status`、实际文件及大小，核对文件位于临时目录内并与 Canvas 元数据相符，再移入对应分类目录，遇同名时禁止覆盖。链接失效时重新列文件获取新 URL。归档后检查实际路径，并报告新增、复用和失败项。
