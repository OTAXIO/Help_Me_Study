# 指定文献学习

先识别必读/复现/方法来源/补充及本次问题，核实版本/题名/作者/年份/DOI。优先现有全文；需要获取时读当前 `nature-downloader` 并遵守其实际访问和补充材料流程。只摘要、节选或二手材料时标阅读边界，不能声称已读全文。

| 需求 | 按需加载 |
|---|---|
| 关键段落、公式、图表、来源问题 | `nature-reader` 的问题/节选路线 |
| 核心论文的完整方法与证据拆解 | `nature-paper-card`，必要输出留 work，不强塞课程报告 |
| 引用元数据/DOI 不一致 | `nature-ref-verifier` |
| 缺全文 | `nature-downloader` 或已有合法全文工具 |

读相应 SKILL.md 及所要求的必要资源，遵守其来源定位与检查，不把“可调用”说成“已调用”。局部问题不强制翻译全文，精读卡不能替代课程最终产物。

对直接影响任务的正文、算法、公式、图表、附录/补充材料充分研读：动机、假设、数据流、边界、参数、预处理、基线、指标、主要结论和局限。记录稳定页码/节/公式/图表定位，不编造页码。

建立“原文方法/证据 → 老师要求/课程约定 → 本次实现/报告”对应。对照课堂先排除符号、条件和版本，实质差异说明双方来源、影响与建议；老师决定任务和指定方法，已知数学错误不能冒充正确。报告必要时说明简化/偏差，不擅自换方法。

从文献摘取的数值和原图不能当成本次实验。未复现/未验证的结论标明，引用放相关论述附近。
