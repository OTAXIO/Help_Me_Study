# 课程报告

默认中文 LaTeX → PDF，教师指定模板、语言、题目顺序、篇幅/格式优先。源/图/引用/编译产物在 report，最终 PDF 和要求源码放 submit。Overleaf 先准备完整源目录，用户要求压缩后才打包。

| 具体工作 | 可用技能 |
|---|---|
| 起草、重构问题—方法—结果—分析 | `nature-writing` |
| 既有文字精简、润色、LaTeX 修复 | `nature-polishing` |
| 科学图、多面板图与可复现绘图 | `nature-figure` |
| 文献元数据 | `nature-ref-verifier` |

调用前读实际入口与匹配资源；保留课程中文、范围和模板，不套 Nature 投稿、双栏或英语默认，不因主文精简丢评分推导/实验。不需要专业流程时直接用已有工具完成，不假装调用过。

## 先确定项目问题与证据结构

写新报告或整体重构前，先明确项目要解决的实际/理论问题、意义、现有基线的限制、具体研究问题、判断成功的指标与范围。目的不能只有宽泛背景；方法选择要能说明为什么适合该问题。

用[实验关系表](../templates/experiment-map.md)在内部工作记录中映射“问题 → 实验目的 → 对照/变量/条件 → 指标与证据 → 实际结论 → 仍未解决的问题”。简单任务可简写，不为局部措辞修改重跑完整分析；不默认增加报告大纲审批。

## 每个实验为什么做、怎样比较

对每个实验说明：它检验哪个问题/假设/选择/限制，为什么需要，比较谁、为何选该对象，改变什么、控制什么，指标如何回答问题。数据、预处理、训练/计算预算和重复条件须按实际情况交代；存在不可比因素就说明，不虚构公平性或统计显著性。

结果回答该实验原本的问题，选择有意义的比较解释，不逐项复述整张表。区分原文结果、本次实测、理论预期；说明结论与不能推出的内容。每个重要判断有数据、推导或来源。

## 实验之间的关系

| 关系 | 如何展开 |
|---|---|
| 并列 | 同一上层问题的不同方面，按共同维度组织，不虚构先后依赖 |
| 顺序/依赖 | 后者实际使用前者的参数、模型、数据或选择，按依赖展开 |
| 递进 | 先确认现象/有效性，再解释或检验，进一步讨论边界 |
| 对照 | 清楚标明基线、改变因素和可比较条件 |
| 因果 | 仅设计与证据支持时表述，不能把先后/相关直接当因果 |

报告的论证顺序与实验实际执行顺序分别记录。不能为“层层递进”倒写决策历史，把事后发现变成预先计划，或把独立实验编成因果链。

## 大节、小节、段落

大节形成问题与证据的推进，可按“问题/限制 → 方案/理由 → 核心验证 → 深入解释或检验 → 适用范围/局限 → 回答目标”组织，但不是固定目录。每节明确解决什么、剩什么，下一节为何出现。教师固定章节/题序和评分内容优先。

大节内小节按知识依赖、方法流程、实验目的与必要顺序排列；并列实验平行展开，依赖实验顺序展开，设置—结果—解释相互对应。不能仅照运行日志先后拼成报告。

段落与章节衔接应用[叙事与段落逻辑](narrative.md)：一个主要任务、证据支持判断、判断服务本节，转换有真实关系。客观课程报告不套演讲口吻。主体与时间检查见[身份与时间](voice-and-time.md)，避免在“本文/本项目/我们”间无依据切换。

既有报告重构先读实际源文件，保留有效实验、表、图、计算与引用；不要运行会覆盖人工修改正文的旧生成脚本。

应用[排版规范](formatting.md)，编译后依[验收](verification.md)看每页。源能编译、PDF 已导出、实际已视觉核验、未压缩源目录可用分别记录，不能合并。
