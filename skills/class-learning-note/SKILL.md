# 课堂学习笔记

先读[共享边界](../help-me-shared/references/core.md)和[共同写法](../help-me-shared/references/notes.md)。本入口负责课堂流程；笔记怎样讲清楚只在共同写法中维护。

## 先读材料，确定本讲在教什么

涉及 Canvas 课程时，先按[Canvas 路线](../help-me-shared/references/canvas.md#补下载课堂资料)核对本地文件并补下载缺项，归入课程目录直属的 `资料/课件`、`资料/作业` 或 `资料/其他文件`。只要求补下载时，完成归档并报告结果即可。

读取课件、匹配的课堂视频字幕、老师任务和口头要求，再读已有笔记。字幕获取按[Canvas 路线](../help-me-shared/references/canvas.md)；已有 Notion 页先交[同步技能](../help-me-notion-sync/SKILL.md)只读定位。

课堂字幕、老师课件与任务是主体和判断标准。用课件搭骨架，用课堂讲解补动机、直觉、例子和强调。字幕有噪声时回到画面、课件或上下文核对。分别标明“课堂已讲 / 课件拓展 / 预习 / 课堂覆盖待核实”，没有可靠课堂证据就用最后一种。

网络资料只补课堂材料讲不清、有缺口或需要直觉与图示的位置，标“外部补充”并给出处。与老师讲法不一致时先查条件、符号和版本；课程方法以老师为准，把差异及影响写出。确认的事实或数学错误不能照写成正确结论。

老师布置或强调的作业、实验、考核方式、截止时间交给 [help-me-assignment](../help-me-assignment/SKILL.md)核验，引用其要求清单和来源，不另建权威核验流程。将结论放进章节“本讲任务”和课程层面的“考核与提交要求”页，互相链接。每项任务连接到教会读者完成它的定义、步骤、小例子和完成检查。项目课还要根据实际文件与结果写明“现在做到哪一步、还剩什么”，不把待做事项说成已完成。

## 先呈交结构和大纲，等待确认

用[课堂大纲模板](../help-me-shared/templates/outline.md)展示阅读路线、每章问题串、知识依赖、解释顺序、具体小节、任务落点、配图问题、来源覆盖和缺口，以及旧笔记保留/调整/新增范围。页面树保持课程入口 → 章节子页 → 必要拓展。

等待用户明确确认。等待期间可整理、核验来源，不写完整正文，不创建正式章节或改正式 Notion 正文。已有确认继续有效，不变成逐节或逐批审批。明显改变范围或结构时重新展示大纲；局部勘误和格式修复沿用已批结构，不重写无关正文。

跨会话按[运行工具](../help-me-shared/references/runtime.md)记录大纲指纹和真实确认。指纹改变后判断是否超出原授权；工具回执不能制造用户同意。

## 按已确认结构，小批次生成和核验

每批如 1—2 章，按共同写法完成正文、推导、例子和配图。公式和例子实际核算。每批通过后继续，除非用户另要求逐批审核。

先读[排版规范](../help-me-shared/references/formatting.md)，按[格式检查](../help-me-shared/references/format-validation.md)核对标题、段落、样式、列表、公式、代码、表格和资源。源结构、转换后的节点与最终显示分别验，标记成对不代表通过；通用 Markdown 预览不能证明 Notion 或数学排版正确。

按共享边界确认用户已授权写入，并完成课堂大纲确认后，交[同步技能](../help-me-notion-sync/SKILL.md)执行写前读、资源保留和逐页回读。只供参考或阅读的 Notion 链接作为来源使用。按[验证规则](../help-me-shared/references/verification.md)报告覆盖、实际核验与缺口。
