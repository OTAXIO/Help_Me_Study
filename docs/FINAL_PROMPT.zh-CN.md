## 一、目标与设计

我是上海交通大学学生，主要使用 Windows / PowerShell。材料包括本地文件、SJTU Canvas、课堂字幕、参考文献和 Notion 笔记。

目标：核验要求并充分完成作业；生成便于理解、记忆和复习的中文笔记；维护 Notion 层级并持久保存笔记位置。重视要求覆盖、清楚解释、实际可用产物和真实验证状态。

参考现有 nature skills：统一入口、独立子技能、共享规则、references 按需加载。先检查可访问的代表性 nature 技能，不复制无关论文工作流。指令精简，只保留会影响决策或减少错误的规则。共享规则单一维护，不默认开启多代理。

## 二、技能结构

在 `skills/` 下设置：

- `help-me-study`：完整学习任务和组合任务的入口、路由。
- `help-me-assignment`：要求获取、拆解、课堂核验、评分与交付清单；只分析时不擅自实现。
- `help-me-homework`：完成解答、代码、实验、报告和最终材料，复用已有要求分析。
- `help-me-notes`：笔记结构、大纲、确认后的正文、配图、自测及来源边界。
- `help-me-notion-sync`：页面定位、资源保留、层级、同步、回读与位置映射；不重复承担正文生成。
- `help-me-speech`：PPT 演讲稿，先确认风格、时长、听众目标，再组织主线并核对主体、人称、时间。
- `help-me-shared`：共享规则、模板和脚本，不伪装成可调用技能。

每个可调用技能有独立 `SKILL.md`、清楚的触发描述和可独立使用的入口。只加载当前相关资源；单题解释、局部修订不强制启动全流程。安装后共享引用必须有效。

## 三、Canvas 与字幕

要求核验和笔记生成均可调用已有 `sjtu-canvas-skill`。安装位置示例为 `%USERPROFILE%\.codex\skills\sjtu-canvas-skill\SKILL.md`；实际运行须发现当前安装位置，不硬编码个人路径。

先读其 `SKILL.md`，按需读 references。复用 `list-courses`、`list-assignments`、`list-files`、`list-videos`、`download-subtitle`、`study-note` 等真实能力。中文课程名先解析 ID，匹配课程、学期、日期、讲次和材料，不猜测 ID，复用有效缓存。

从字幕核验作业范围、必做/选做、指定方法、报告、评分和提交说明，保留页码、日期和可用时间戳。区分正式要求、明确口头补充与一般讨论。含混自动字幕不能成为确定结论。获取失败按现有技能排查/降级，不能声称没有录像。

通过本地配置加载凭据，避免缺少配置时挂起；不打印、提交或 shell-source 带凭据的 `.env`。

## 四、明确作业要求

先清点并完整阅读本次任务书、评分标准、课件、Markdown、相关图表与代码说明。扫描页、公式和图示查看原页，不能只靠文本提取、文件名或旧作业。记录缺失材料及影响。

需要核验口头要求、材料不全或用户要求结合课堂时，获取对应字幕。来源冲突记录双方位置与时间，查找明确修订；影响范围、方法或提交格式的关键歧义需要询问，同时继续独立准备。

建立“要求—来源—对应解答/代码/实验/报告—提交文件与格式—验收—状态”清单。区分老师要求、用户补充和自行建议。

开始生成作业前展示简洁摘要：做什么、交什么、如何验证。明确时继续，不新增常规审批；关键歧义或用户要求先审核时等待。

## 五、参考文献学习

识别必读、方法来源、复现对象和补充文献，记录对应任务，核实题名、作者、年份、版本和 DOI。优先用户全文，缺少时合法获取。不仅凭摘要或二手总结声称研读/复现全文；如实说明阅读范围和限制。

按需调用并先读说明：`nature-reader`（原文、公式、图表和来源问题）、`nature-paper-card`（核心论文方法与证据）、`nature-ref-verifier`（元数据）、`nature-downloader`（合法全文）。不默认加载全部，不为局部问题强制生成双语全文或完整精读卡。精读中间资料不自动进入 submit。

理解动机、假设、定义、推导、算法、实现、边界、数据、预处理、参数、基线、指标、图表、结论、局限和影响任务的附录/补充材料。建立“文献—老师要求—本次实现/报告位置”对应，区分原文方法、课程修改与自行扩展。

与老师不同，先排除符号、条件、约定和版本差异。实质差异说明双方、来源、影响和建议。任务范围、指定方法、交付和考核口径优先老师明确要求，不擅自换方法；已核实的事实/公式错误应提出，不能写成正确结论。必要时在报告简洁说明约定和改动。

## 六、评分与改进

读取公开 rubric、评分表、公告与明确课堂说明，提取分值/权重、必备、加分、扣分和硬限制。未知标未知，不编造隐藏规则。

建立内部表：“评分项—公开权重—要求—产物—证据—验证—缺口”，不自动放入正式报告。先消除遗漏、错误、无法运行、接口/格式违规和缺文件；再覆盖高权重项；基础完成后增加有价值的对比、消融、误差、边界、讨论或选做，不堆无关内容。

数学正确且推导充分；程序满足接口与边界；实验设置清楚、对比合理、结果真实、分析解释现象；复现说明原文与本次设置和偏差；报告直接答题便于评分。逐项验收，不凭外观声称完整，不伪造结果/引用或保证分数。

## 七、工作目录

新任务默认在任务目录创建 `work/`：`code/` 放代码及相关配置，`report/` 放报告源文件/图表/编译产物，`submit/` 放最终材料。

work 被其他内容占用时用 `work_codex`，均占用时用不覆盖的后缀。继续同一任务复用经确认的目录。不搬动、改名或覆盖原始材料。新增下载、字幕、草稿、结果和 QA 按需放工作目录，不建无用空模板。跨会话页面映射放独立本地用户目录。

submit 内命名、格式和层级按老师要求，只放正式材料，不打包整个 work。

## 八、先整理 submit，等待指令再打包

写入 submit 后保留未压缩文件/目录。用户明确要求“打包”“压缩”或同等操作前，不创建 ZIP、7z、tar 等归档，包括提交包和 Overleaf 源码包。

老师要求压缩包也先备好目录和文件，标注“待用户指令后打包”，不自动压缩。先检查完整性、命名、路径、运行和版式。收到明确指令后再压缩并检查内部内容与解压可用性，不重复索取同一授权。

未打包时报告“提交材料已整理并检查，尚未打包”，不混同上传或课程提交。所有源文件包/压缩包要求受此条约束。

## 九、作业内容与真实交付

充分完成必做推导、实验、对比、图表和分析，不以空泛文字、示例或框架冒充完成。缺口说明条件和影响。

保留真实代码、环境、配置、输入、结果和复现步骤。区分实测、文献值、理论预期、未验证。不虚构训练、日志、截图、数值或提升，不交陈旧接口/配置。

正式表达自然准确，不出现“作为 AI”“下面为你生成”等口吻，不放 prompt、聊天、Codex 标记、内部 QA 或无关日志。注释解释代码，不编造经历或独立完成声明；老师要求的工具声明如实保留。过程资料不进 submit。

HPC 仅相关时加载规则，遵守计算节点限制，登录节点不跑重负载。缺身份不猜；耗时训练、付费 API 或超范围操作判断授权。

分别报告已编写/已运行/已编译/已导出/已视觉检查/已整理/已打包/已提交。课程提交只在用户明确要求时执行。

## 十、报告与 nature skills

正式报告默认必须使用中文 LaTeX → PDF，用户无需每次重申。完整主 `.tex`、章节、图表、引用与必要样式放实际工作目录的 report，实际编译并检查每页后，最终 PDF 放 submit；是否提交源码按老师要求。Markdown 仅作为内部大纲、草稿或说明，不能替代正式报告，不能仅改文件后缀。

教师语言、题序、篇幅及兼容模板须遵守；教师未指定格式、只要求 PDF 或提供 Markdown 任务说明，都不构成改交 Markdown 的依据。用户明确变更格式时采用其决定；老师明确要求不兼容格式时先核实依据与已确认决定，重要冲突未解决再询问，不能静默变更。编译器缺失或编译失败时先尝试已有工具与合理修复，仍受阻则保留 LaTeX 源码、说明 PDF 缺口并标报告未完成，不能自行降级。无需报告、只要大纲/审阅/源码的任务遵守实际范围。

调用 nature 写作工具时传递 LaTeX 输出约定，其 Markdown 返回内容仍需组织成可编译工程。交付前核对完整源码、最新实际编译、PDF 与实验内容及每页显示；仅有 Markdown、旧 PDF 或缺失资源不能算报告完成。Overleaf 先备可用源目录，压缩等明确指令。

按需用 `nature-writing` 组织证据和起草/重构，`nature-polishing` 润色/精简/LaTeX 修复，`nature-figure` 图表，`nature-ref-verifier` 引用。先读说明，不自动套期刊、英文、双栏或投稿流程，不因精简删去评分内容。论述有真实来源，引用靠近相关内容，文献/实测/理论分清。

## 十一、笔记先审结构大纲，确认后正文

阶段 A：读课件、字幕和旧笔记；涉及 Notion 先读父子页。展示范围、章节细纲、知识依赖/解释顺序、父/章/拓展树、配图计划、来源覆盖和缺口、保留/调整/新增。大纲足以核验，不只有空标题。

等待确认或修改。期间可整理/核验资料，不生成完整正文、不建正式章节、不改正式 Notion 正文。

阶段 B：按确认范围生成，不重复审批。明显改整体结构先展示；局部修订沿用确认。按小批次（如 1—2 章）生成并内部核验，通过后继续，除非用户要求逐批审阅。

## 十二、笔记教学、记忆与层级

课件为骨架，课堂补直觉、例子与强调，不堆字幕。区分“课堂已讲”“课件拓展”“预习”，不明则“课堂覆盖待核实”；课件存在不是已讲证据。外部补充注明来源。

默认高细节中文复习材料，灵活按：问题/动机—直觉—定义/原理—公式/推导—例子—条件/局限—易错—联系。解释为什么、符号/维度/假设，以及必要的连续到离散、流程/复杂度/参数/对比/反例。不机械套标题，不堆名称。

用小结、对照、关系图、自测和复习顺序助记，口诀不牺牲准确性，答案便于先思考后看。关键公式与例子实际核算。

课程入口 → 章节子页 → 必要拓展子页。主线在章；长推导/背景/进阶可入章下并链接，避免过深碎片化。整体重排/局部改动遵守范围。

适当用 PPT 图表/局部截图及自绘流程、结构、坐标、关系图。图近解释，注课件页码/原文/教学示意，说明读法结论，保留绘图源。

## 十三、公式、代码、图表排版

正常尺寸清楚，笔记便于学习、报告便于评分；不靠小字号、紧挤、糊图塞内容。

公式：原生数学块/环境，短式行内，关键/复杂式独立；推导对齐换行，解释变换。完整括号（如 `\frac{a}{b}`），核对上下标、矩阵、分段、求和条件。符号/单位统一，初见释维度假设；需引用编号交叉引用。OCR 对原页，数学与渲染分别核验，回读不等于视觉证明。

代码：代码块、等宽、语言、缩进、合适行长字号，可复制不用截图，排版不改语义。笔记例最小完整有输入输出；报告放关键实现，全文在 code，附录/提交遵要求。区分伪代码与运行代码，说明输入输出条件；核查 LaTeX 中文/字符/分页/依赖，改代码同步输出。

图：明确问题读法，图题/注/坐标/单位/图例/色标/分图标记完整，符号一致；按嵌入尺寸看字号。颜色配线型标记，尺度合理一致。真数据绘图留代码/数据，不用生成图伪造曲线。示意正确无重叠，来源区分。矢量优先，栅格按尺寸足够分辨率（约 300 dpi 为报告绘图参考），不把低清放大当清晰。查标注/误差线/图注裁切。

表：原生表格，表头/单位/条件/注完整，精度一致，数值易比较；误差统计有依据；宽表拆/优化/调页，长表重表头，不缩到不可读；高亮克制，不仅靠色；与正文/图/结果一致。

页面：层级/字体/间距/编号/引用统一，修复孤标题、重叠、越界、空白和图文分离。解释—公式/代码—例子—图—小结关联；不能把必做评分内容藏到难找位置。

## 十四、Notion 位置与同步

本地机制保存课程/学期、核验 Canvas ID、父页与章节/拓展页标题/URL/ID/父子、资料位置、核验时间。不依赖模型记忆或宿主全局记忆文件。用户目录可配置，技能更新不覆盖，仓库只匿名示例。

首次用户提供/确认后记录；以后先查映射再读真实页核对，不重复索取有效链接。歧义/失效/权限变化重定位，仅不能确定时问。支持查看/更正/更新，区分不存在与暂不可访问。

先读父子页/资源，复用章节，保留附件/作业入口/导航/指定内容。大改留本地恢复快照，按当前工具分批写，超时先回读再重试，已授权不重复问。

回读父页及所有受影响页，查层级/导航/公式/图/附件/重复/遗漏/未知块/未解析。区分已接受/已回读/已视觉确认；不可用交本地稿并说明未同步。

## 十五、不确定时选择与询问

所有技能先查材料、偏好、上下文，能查证/验证先自解；仍不明且实质影响结果才询问，不事事问、不猜关键。

应问：实质来源/评分冲突；明显改变范围/方法/结论/交付/结构的取舍；关键条件数据缺失；课程学期页面边界不明；超授权或重要时间费用取舍。

可自定：已明确/已确认；常规实现措辞排版；低影响可逆；有合适默认。必要时说假设，不推小选择。

询问说不确定点、影响、必要性，给少量选项/推荐，合并同阶段问题。等待做独立工作，关键依赖等答案，沉默非同意；回答记录复用。笔记大纲确认保留，不扩大为逐节审批。

## 十六、验收

深度与风险相称，查实际文件。核对要求/评分/证据、文献范围差异、数学数值、代码配置报告一致；做必要有效测试，不堆重复实现测试。

编译后看 PDF，完整报告查每页，局部查受影响页；Notion 回读并尽可能看显示。修复后重生成检查。编译/接口成功或文件存在不证明正确和清楚，未查明说。

明确打包后才建包、检查内部和解压；未打包先查散装源目录。

技能行为覆盖：只分析不实施；字幕文献评分可追溯；目录冲突不覆盖；代码报告 submit 正确；大纲未批不生成；章节拓展层级；新会话定位；资源保留；超时回读；公式代码图表可读；submit 正式且未授权不压缩；不虚报已读/运行/显示。

脚本实际运行；外部验证模拟或隔离，未授权不写真笔记/提交作业。

## 十七、分发与交付
