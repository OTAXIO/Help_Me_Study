# 演讲与报告增量制作 Prompt（v1.1）

在现有 Help Me Study 仓库 <https://github.com/OTAXIO/Help_Me_Study.git> 中增量更新，保留原有技能、笔记大纲审批、评分核验、工作目录与“submit 明确指令后才压缩”等规则。当前只审阅 prompt 时不实施；明确要求实施后再改仓库/已授权全局安装。

## 新增 help-me-speech

根据 PPT/PDF 幻灯片和相关材料生成可朗读的个人化演讲稿。加入总路由、清单、UI、安装、说明和验证，资料按需加载。

### 必须先确认

每个新稿先确认三组信息：希望风格/正式程度；目标时长/硬上限/翻页演示互动留时；听众及其背景、希望理解/记住/达成什么。已给的信息直接复用，只把缺项合并询问。等待可读材料核事实，不缺项定稿，不随意默认五分钟/正式/同学。同一任务修改沿用已确认条件。

条件够后可直接出完整稿，不默认加提纲审批；用户要求先审提纲时再等待。

### 个人声音与场景

优先用户提供/指定/确认的风格样本，区分亲笔和认可的辅助稿。有可用风格检索则遵守其规则取相关样本；不无范围扫描私人文件、缓存完整检索样本或公开。无样本依明确偏好，不声称全面分析。

真实具体、自然克制、有观察和判断，保留工科生对问题/条件/方法/证据/结果的重视，说明做什么、为何做、认识到什么。理性有温度，不堆术语口号，也不每段变说明书。

鲁迅、余华等参考落实为细节、朴实、情绪克制、长短句、经历到认识、事实反差等通用叙事技巧，不直接复刻在世作家独特文风、标志句式或他人经历，不太文艺。

正式可参考公开政府讲话/正式致辞的结构、层次、分寸和承接，适合当前身份，不带入立场、政绩、宏大承诺或空话。活泼可参考脱口秀等的铺垫、节奏、反差、停顿、回扣，适量有依据的自嘲，不编故事、不复制特定演员表达、不强塞段子。技术/自然/混合按听众目标调整。确需外部参考时实际读可靠公开文本后才声称参考。

### PPT、主线与衔接

完整读相关页、图表、备注、附录，核版本、页序、数字、贡献和状态；冲突看来源/版本，关键问清。不擅改原 PPT，顺序影响叙事可提建议。

明确总体主线，每页承担背景/问题/经历/方法/结果/认识等任务，避免逐页机械扩写。按听众解释背景和术语，按时长分配重点，给停顿展示留余量。字数/语速是估时，未试讲不声称实测。

段内围绕主要任务，句间有真实关系。段间承接事实、问题、结论、认识或边界，跨页说明转向理由；并列说明共同目标，不强编因果。连接词标关系，不造关系。结尾回开场，用证据支持的认识收束，避免突兀拔高。语言可朗读换气，页码提示与正文区分，不混内部分析。

### 主语、人称、贡献和时间

先确定谁在讲、身份、讲谁、面对谁、实际演讲时间。内部对应资料作者/被介绍者/团队、行动与归属、时间状态及来源。

统一当前叙述者，参考中的“我/我们/你们”先解析再转换；引语边界清楚，引用外恢复当前身份。省主语可自然但指向唯一。区分我负责/我参与/团队完成/他人负责，不夸个人也不模糊具体工作。多主体用明确称谓，动作、感受、认识主体匹配，不将参考作者经历移给用户。

区分已完成/正在/尚未/计划；在投/录用/发表不混。旧文今年/去年/目前/明年按实际时间锚点重定位，必要时绝对日期，关键未知先问。中文核时间词/体貌/修饰/状态，英文另核时态、主谓一致、代词和语态。定稿单独做主体与时间检查，不只改错字。

## 增强报告生成

增强 `help-me-homework` 和共享 report 流程，不重复建报告技能。保留老师结构、评分、有效实验、数据、表图和引用。

先明确项目问题、意义、基线限制、具体研究问题、成功指标与范围。每个实验交代为何做、检验什么、对照谁及理由、改变/保持条件、指标/证据、发现与不能推出的结论。按实际情况说明可比条件，不虚构公平或显著性。

内部映射“问题—实验—对照/变量—证据—结论—后续问题”。区分并列（同一上层问题多方面）、顺序/依赖（后者确实使用前者产物）、递进（现象到解释/边界）、对照、以及有证据的因果。先后不是因果，不为递进倒写决策历史或把事后认识伪装为预先假设。

大节形成问题/限制—方案理由—核心验证—进一步检验—边界—回答目标的推进，可灵活选取，不是固定目录。每节解决什么、剩什么、下一节为何出现要清楚。小节按知识依赖、目的、流程与必要实验顺序；并列平行、依赖顺序，设置/结果/解释对应，不照日志拼稿。

每段有功能和中心，证据支持判断，判断服务章节；结果解释关键比较，不逐条复述表。转折有真实关系，讨论不超证据。用反向提纲检查段→节→项目问题。报告保持客观学科表达，不套演讲个人口吻。

按需用 nature-writing / nature-polishing / nature-figure，读实际入口与需要资源，可借鉴段落流动和证据链，不删课程评分内容。既有源文件直接改，不运行会覆盖人工修改的旧生成器。

## 实现与验证

共享叙事、身份时间、风格及演讲 references 避免重复；补必要需求/主体/实验关系模板。数量检查从清单读取，安装升级先比较哈希并保留本地改动和用户状态。

验证缺项先问/已知不问、不同风格适配、PPT 主线、跨作者人称/团队贡献、相对时间/状态、段落跨页、实验关系/大节递进、事实不被润色改变，以及安装共享路径。实际样例与人工阅读评价语义，不用句式关键词测试冒充语义证明。

稿件进 work/report 合理位置；Word/PDF 按需并看实际版式。不未经要求改 PPT/写 Notion/发送，正文不含内部分析。submit 保持未压缩。明确报告实际验证、未做项、GitHub 与全局安装状态。
