日期：2026-10-30（Asia/Shanghai）。本次修复针对正式报告被 Markdown 草稿替代的问题；没有修改任何真实课程报告。

## 修复范围

总入口、作业入口及调用提示明确：任务包含完整报告时，保留完整 LaTeX 工作源码，实际编译 PDF 并检查，再整理最终 PDF 到 submit；用户不必重复指定 LaTeX。要求核验、要求模板、报告路线、交付流程与验收采用同一约定。

Markdown 仅作内部大纲/草稿/说明，不能替代报告。明确了缺编译器/编译失败、旧 PDF、已有 Markdown 文稿、外部写作能力返回 Markdown、仅要求 PDF 及教师不兼容格式等情形；用户只要部分工作或无需报告时保持范围。未授权不压缩规则继续有效。

## 验证范围

以下是人工规则走查，不是独立模型行为测试：

- 用户只说“写报告”，不再次提 LaTeX：总入口与作业入口均明确 LaTeX/PDF，要求摘要与验收可追踪产物。
- 已有 `report.md` 或工具返回 Markdown：保留有效原稿并实质转换，不允许只改扩展名或把草稿算交付。
- 无编译器、编译失败或只有旧 PDF：保留源码、据实标记报告未完成，不自行降级格式。
- 老师明确要求不兼容格式：核验原文、复用用户决定，未解决的重要冲突集中询问。
- 只要大纲、审稿、源码或无需报告：按实际范围处理，不额外完成整份报告或虚报验收。
