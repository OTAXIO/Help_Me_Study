# 同一作者演练：报告论证

依据 [合成输入](report-context.md) 和 [报告规则](../../skills/help-me-shared/references/report.md) 自审，不是独立评测、真实实验或正式课程报告。

## 结构与关系

项目问题：固定预算下是否改善跟踪误差；随后问模块比较提供什么支持、不同条件下是否仍有适用边界。

- E0 → E1/E2/E3：真实配置依赖。
- E1 → E2：报告中从主要比较进入模块检验的论证顺序，不冒充实际实验顺序或新发现驱动的决策史。
- E3a 与 E3b：同一边界问题的并列考察，不合并成连续叠加条件。
- 一次对照不支持统计显著、普遍机制或跨条件因果保证。

## 大节与节选

### 1. 固定预算下的主要比较

项目首先需要回答的是，在给定计算预算内，完整方案是否能改善位置跟踪误差。报告先呈现相同数据与预算下的主比较：基线 MAE 为 5.0 mm，完整方案为 4.0 mm。该次结果支持完整方案在这一设置下获得更低误差，但还不足以区分各组成部分的作用。

### 2. 模块对照提供的局部证据

为考察组成部分与表现的关系，固定其他条件，比较完整方案和移除模块后的方案。移除后 MAE 为 4.6 mm，高于完整方案的 4.0 mm。该对照为模块在当前条件下的作用提供了支持；只有单次结果，尚不能据此宣称统计显著或普遍因果。这里的呈现顺序服务于问题解释，实际执行日志中 E2 早于 E1。

### 3. 两种变化条件下的边界

上述比较针对固定设置，仍需观察条件变化时的表现。噪声变化与负载变化分别考察：E3a 为 4.3 mm，E3b 为 4.5 mm，两个条件均未叠加。它们从不同方面提示误差随测试条件变化，不能把两者连成先后导致的因果链，也不能从有限条件推断一般鲁棒性。

## 观察与未验证

每节承接上节未解问题，小节对照/条件明确；保留所有给定数字，未伪造重复试验或显著性。该演练检查文字结构和证据边界，未生成 LaTeX/PDF、图表或运行真实算法。
