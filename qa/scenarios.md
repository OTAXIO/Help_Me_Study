# 决策场景与验证边界

v1.2 增加[综合格式样例](cases/format-good.md)、[结构期望](cases/format-good.expect.json)、[原生快照](cases/notion-native-format.json)和[实际验证](validation-v1.2.md)。解析测试和本地浏览器检查不代表真实 Notion 或数学排版通过，不自动改写笔记。

v1.1 新增[演讲合成输入](cases/speech-context.md)及[同一作者自审稿](cases/speech-self-review.md)、[报告合成输入](cases/report-context.md)及[自审稿](cases/report-self-review.md)。这些是非独立的规则演练；自动测试新增安全升级/备份/本地改动保护，不将文字匹配当语义验证。

以下是合成场景与人工规则走查，不是独立模型前测，不声称已经完成真实 Canvas/Notion 任务。自动测试覆盖辅助 CLI 和安装的可观察行为，不能替代模型的语义行为评估。

| 合成请求/条件 | 应出现的行为 | 本次检查方式 |
|---|---|---|
| 只核验老师要求，先别做 | 只建要求/评分/来源清单 | 检查 assignment 入口与路由边界 |
| 任务书和字幕指定方法不同 | 查版本/条件，重要冲突问用户，来源可追溯 | 检查 assignment/literature 规则 |
| 完成全部作业，老师要求 ZIP | 散装整理 submit，待明确打包 | 检查 homework/core/最终 prompt 一致；CLI 无打包功能 |
| 只给课件，无可靠课堂字幕 | 标已讲覆盖待核实，不冒充课堂证据 | 检查 canvas/notes 规则 |
| 生成笔记，大纲未确认 | 停在大纲；不能写正式页/完整正文 | 检查 notes 入口；CLI 默认 pending 与改纲失效测试 |
| 同一课程跨两学期有映射 | 不自动挑一个学期 | CLI 实测歧义错误与指定学期成功 |
| 旧 work 和 work_codex 都占用 | 不动旧文件，创建 work_codex_2 | CLI 实测原文件字节保留 |
| 更新旧 Notion，含附件和章下拓展 | 先读后写，保留资源，逐页回读 | 检查同步规则；映射树无环/连通验证 |
| 写入超时可能部分成功 | 先回读，补缺，不盲重试 | 检查 notion 规则；未连接真实服务演练 |
| 新会话直接说更新某门课 | 本地映射定位，仍需读真实页 | 冷进程 CLI 读取持久映射实测 |
| 长公式、代码、宽表、低清图 | 分别处理正常尺寸阅读和原始依据 | 排版规则走查；未生成真实课程报告/图 |

后续真实使用应以原始材料和可观察产物评价，发现偏差再窄修。不能用匹配某句指令的测试声称代理已正确执行。
