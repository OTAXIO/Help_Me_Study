# 决策场景与验证边界

v1.2 增加[综合格式样例](cases/format-good.md)、[结构期望](cases/format-good.expect.json)、[原生快照](cases/notion-native-format.json)和[实际验证](validation-v1.2.md)。解析测试和本地浏览器检查不代表真实 Notion 或数学排版通过，不自动改写笔记。

v1.1 新增[演讲合成输入](cases/speech-context.md)及[同一作者自审稿](cases/speech-self-review.md)、[报告合成输入](cases/report-context.md)及[自审稿](cases/report-self-review.md)。这些是非独立的规则演练；自动测试新增安全升级/备份/本地改动保护，不将文字匹配当语义验证。

以下是合成场景与人工规则走查，不是独立模型前测，不声称已经完成真实 Canvas/Notion 任务。自动测试覆盖辅助 CLI 和安装的可观察行为，不能替代模型的语义行为评估。

| 合成请求/条件 | 应出现的行为 | 本次检查方式 |
|---|---|---|
| 只核验老师要求，先别做 | 只建要求/评分/来源清单 | 检查 assignment 入口与路由边界 |
| 任务书和字幕指定方法不同 | 查版本/条件，重要冲突问用户，来源可追溯 | 检查 assignment/literature 规则 |
| 完成全部作业，老师要求 ZIP | 散装整理 submit，待明确打包 | 检查 homework/core/最终 prompt 一致；CLI 无打包功能 |
| 写实验报告，用户未再次提 LaTeX，老师只要求 PDF | 仍生成完整 `.tex` 并实际编译 PDF，不交 Markdown 草稿 | v1.2.1 入口、要求摘要与报告完成条件人工走查 |
| 本次已有 report.md，或文稿工具返回 Markdown | 保留原稿，实质转换成 LaTeX 后编译检查，不能只改后缀 | v1.2.1 报告路线与调用提示人工走查 |
| 编译器缺失/编译失败，或目录只有旧 PDF | 保留源码并说明报告未完成，不能改交 Markdown 或冒称编译成功 | v1.2.1 报告路线与验收人工走查；未模拟真实编译环境 |
| 老师明确要求不兼容的可编辑模板/报告格式 | 查原文、复用已确认决定，未解决的重要冲突询问用户 | v1.2.1 要求流程与报告规则人工走查 |
| 只要报告大纲、审稿或无需报告的代码任务 | 遵守实际范围，不额外生成完整报告或虚报已验收 | v1.2.1 总入口与作业入口人工走查 |
| 只给课件，无可靠课堂字幕 | 标课堂覆盖待核实，不冒充课堂证据 | 走查 class-learning-note 与 canvas 路线 |
| 课堂笔记大纲未确认，已明确要求写入指定 Notion 页面 | 停在大纲，允许只读定位；不能写正式页/完整正文 | 走查课堂入口与同步边界；CLI 默认 pending 与改纲失效测试 |
| 网络调研范围清楚，用户要学会一个工具 | 直接核验和写作，不等课堂大纲批准；说明平台、版本、前置条件、成功核对方法 | 走查 online-research-note 操作路线；未联网实测真实教程 |
| 网络调研需要多页且明确要求写入指定 Notion 页面 | 先告知简短页面结构，再推进；按主题组织，写前读与回读，不伪造课程 | 走查调研、同步与映射边界；未写真实页面 |
| 用户只让参考或阅读一个 Notion 链接 | 按来源读取，交本地稿，未经明确授权不写入 | 走查共享边界、两类笔记和同步入口 |
| 老师任务只列了要做什么，用户问怎样完成 | 引用 assignment 核验结论，连接教学步骤、检查和项目进度证据 | 走查课堂入口与大纲模板 |
| 网络补充与老师方法不一致 | 查条件和版本，课程方法以老师为准，差异写明，已知错误不冒充正确 | 走查课堂来源规则 |
| 读者追问一个前置概念并要求补入笔记 | 补在首次使用前，更新后续称呼，不堆到页尾 | 走查共同写法 |
| 教程命令过时、平台不符、漏前提或评论区已纠正 | 回到当前一手依据，写清哪里错、正确做法与证据；不执行改系统等危险操作来验证 | 走查调研核验路线 |
| 论文性能数值只看过摘要，另有帖子反驳 | 标实际阅读范围及作者报告，追原文和独立证据，冲突和判断依据公开，未复现不标实测 | 走查调研研究路线 |
| 平台视频读不到或搜索未检索到结果 | 换来源并说明访问/检索局限，不把失败或未找到写成不存在 | 走查调研工具路线 |
| 更新移除了旧技能，旧目录完整匹配回执 | 整目录移到私有备份，核对字节，更新回执，宿主目标不再有旧入口 | 自动测试移走、备份内容、回执与重复更新 |
| 旧技能目录有修改、缺失、额外文件或空目录 | 报告并停止整次更新，目录和回执保持不变 | 自动测试四种变化与写入前保护 |
| 更新预演包括旧技能移除 | 返回移除计划，不写文件、回执或备份 | 自动测试全部文件字节不变 |
| 只有旧技能移除、无其他替换，或无回执但有已知基线 | 仍创建完整备份；只处理有依据的套件目录，保留其他技能 | 自动测试单独移除、合成历史基线与无关技能字节保留 |
| 旧技能内有指向外部的链接 | 写入前停止，不移动旧目录，不触碰外部内容或回执 | 自动测试；本机用 Windows 目录联接覆盖保护路径 |
| 同一课程跨两学期有映射 | 不自动挑一个学期 | CLI 实测歧义错误与指定学期成功 |
| work_claude 和 work_claude_2 都占用 | 不动旧文件，创建 work_claude_3；codex 仍用 work_codex | CLI 实测原文件字节保留 |
| 更新旧 Notion，含附件和章下拓展 | 先读后写，保留资源，逐页回读 | 检查同步规则；映射树无环/连通验证 |
| 写入超时可能部分成功 | 先回读，补缺，不盲重试 | 检查 notion 规则；未连接真实服务演练 |
| 新会话直接说更新某门课 | 本地映射定位，仍需读真实页 | 冷进程 CLI 读取持久映射实测 |
| 长公式、代码、宽表、低清图 | 分别处理正常尺寸阅读和原始依据 | 排版规则走查；未生成真实课程报告/图 |

后续真实使用应以原始材料和可观察产物评价，发现偏差再窄修。不能用匹配某句指令的测试声称代理已正确执行。
